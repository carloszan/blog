How am I building a Twitter Clone

September 8, 2025 2-minute read
Carlos Zansavio
Twitter
Clones

I want to build a twitter clone. Currently, I am a data engineer, previously a backend software engineer. I don’t have all the necessary skills to do that. So what I can do is use the clones people already did and use their code.

Requirements Link to heading

  • Frontend app and/or mobile app must be ready.
    • I will only work with the backend stuff.
  • Start simple and complex later.
  • Fully functional in the end with CI/CD.

GithubShaban-Eissa/NextJS-Twitter-Clone Link to heading

  • Projeto interessante.
  • Tem apenas 12 commits e um contribuidor.
  • É feito em Javascript.
  • Tem poucas features, porém features importantes.
  • Não tem tela do usuário.
  • OAuth com NextAuth.
  • Next version: 12.2.5

ccrsxx/twitter-clone Link to heading

  • Projeto maduro.
    • 902 stars
    • 3 contribuitors
    • 111 commits
  • Tem a maioria das features necessárias.
  • Typescript.
  • Next version: 12.3.0

TheAlphamerc/flutter_twitter_clone Link to heading

  • Projeto mobile escrito em Flutter.
  • É o projeto com mais estrelas de Twitter Clone no Github (4200 estrelas).

merikbest/twitter-spring-reactjs Link to heading

  • Projeto maduro.
  • Escrito em React (Typescript) e Java.
  • Microsserviços.
  • Banco de dados: Postgres.
  • Media no S3.
